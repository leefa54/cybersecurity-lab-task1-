## Task 1 - Cybersecurity Basics and Lab Setup

### 1. CIA Triad

Confidentiality - Protects information from unauthorized access.

Integrity - Ensures information is accurate and not changed without authorization.

Availability - Ensures systems and information are available when needed.

### 2. Common Threat Types

Malware - Malicious software designed to damage or gain unauthorized access.

Phishing - Fake messages or websites used to steal information.

Ransomware - Malware that locks or encrypts data and demands payment.

DDoS - An attack that overwhelms a system with large amounts of traffic.

### 3. Attack Vectors

Phishing emails

Weak passwords

Unpatched software

Malicious websites

Infected files or downloads

### 4. Cybersecurity Lab

Kali Linux - Used for security testing and learning.

Metasploitable 2 - Intentionally vulnerable machine used for practice.

Wireshark - Used to capture and analyze network traffic.

### 5. Lab Safety

The cybersecurity lab should use an isolated/private network.

Only test systems that are owned by you or where you have permission.

### 6. Basic Networking

IP Address - Identifies a device on a network.

MAC Address - Identifies a network interface.

Protocol - A set of rules used for communication.

TCP - Reliable connection-oriented protocol.

UDP - Faster connectionless protocol.

### 7. Cryptography

Encryption - Converts readable data into protected unreadable data.

Decryption - Converts encrypted data back into readable data.

Hashing - Converts data into a fixed-length value and is designed to be one-way.
